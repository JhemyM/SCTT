# SCTT - Super Competitive Table Tennis 🏓

Bem-vindo ao **SCTT (Super Competitive Table Tennis)**! Este é um jogo de tênis de mesa desenvolvido em Python utilizando a biblioteca gráfica `turtle`.

## 🎮 Modos de Jogo
- **Single Player (1 Jogador):** Jogue contra a Inteligência Artificial.
- **Multiplayer (1v1 Match):** Jogue contra um amigo no mesmo teclado.
- **Training (Treinamento):** Pratique suas habilidades com configurações ideais para treino.

## ✨ Funcionalidades
- Temas e cores de fundo customizáveis.
- Efeitos visuais dinâmicos (rastro da bola, transparência).
- Opções de som e efeitos especiais.
- Movimento suave dos paddles (raquetes).

## 🚀 Como Executar

Certifique-se de ter o Python instalado na sua máquina (versão 3.x recomendada).

1. Clone o repositório ou baixe os arquivos.
2. Abra o terminal na pasta do jogo.
3. Execute o comando:
   ```bash
   python SCTT.py
   ```

*(Dependência opcional: o jogo possui suporte à biblioteca `simpleaudio` para reprodução de efeitos sonoros. Você pode instalá-la via `pip install simpleaudio` se desejar áudio aprimorado).*

## ⌨️ Controles
- **Jogador 1 (Esquerda):** Movimenta a raquete com as teclas adequadas (consulte o menu do jogo).
- **Jogador 2 (Direita):** Movimenta a raquete com as setas do teclado.

Divirta-se jogando e competindo!
